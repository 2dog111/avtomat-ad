# 1111.bz

Одноэкранный сайт сообщества практиков автоматизации интернет-рекламы.
Основное действие: https://t.me/avtomatad. Публичный адрес: https://1111.bz/.

Статические HTML/CSS/JS в `public/`, без зависимостей и сборки.
Локальный запуск: `python3 -m http.server 8111 --directory public`.

Референс композиции: Mectrics из https://lll.bz/?site=mectrics.
Текст предоставлен владельцем и сокращён по его запросу. Шрифт системный, начертание 400, минимум 18px.
Обычная ссылка работает без JavaScript; с JavaScript сначала открывается Telegram,
при отсутствии перехода в приложение через секунду срабатывает HTTPS fallback.
Ctrl/Cmd-click сохраняет стандартное поведение браузера.

Публикация: копирование `public/` в отдельный статический релиз и переключение
корня Caddy для 1111.bz. Старое приложение магазина сохраняется отдельно.
Не публиковать конфигурацию сервера, ключи, данные магазина и QA-артефакты.

Проверка логики перехода: `node --test tests/telegram.test.cjs`.
