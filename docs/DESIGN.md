# АВТОМАТ AD — устройство страницы

Новый одноэкранный сайт сообщества практиков. Посетители — маркетологи,
разработчики, медиабайеры и предприниматели. Путь: ссылка на сайт → понять
направление сообщества → перейти в Telegram. Успех страницы — доступный переход
в @avtomatad; вступление внутри приложения не измеряется сайтом.

Приоритет: заголовок → объяснение → единственная CTA → аудитория → 10 площадок.
Спокойный технологический характер. Без меню, форм, тарифов, показателей,
обещаний готовых интеграций и дополнительных CTA. Весь текст — из задания.

Выбран Mectrics: светлый фон и центрированная композиция с одной ведущей кнопкой.
Сравнены скриншоты pen.dev (больше навигации и конкурирующих действий) и
Octolens (продуктовая демонстрация и два CTA). Используется принцип иерархии,
а не копия бренда, материалов или исходников.

HTML/CSS/JS без зависимостей, системный шрифт, вес 400, минимум 18px.
Фон #FAFAF8; синяя CTA с белым текстом — по прямому заданию владельца.
На узком экране список площадок уходит ниже первого экрана; CTA остаётся выше.
Ссылка сохраняет HTTPS href при отключённом JS. Reduced motion отключает движение,
reduced transparency оставляет непрозрачную кнопку. Клавиатурный фокус явный.
